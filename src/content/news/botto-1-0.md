Botto 1.0 is out for macOS. Create a Bot, give it a job, and message it like a teammate — it works on its own cloud computer, keeps context on how you like things done, and comes back when your approval is needed.

Everything is open source under MIT, and Bots think with the AI subscription you already pay for. No API keys to buy, no credentials copied to the cloud.
